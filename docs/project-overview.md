# FINWISE — Project Overview

## Project Name
FINWISE — Financial Intelligence & Cost Optimization Platform

## Case Study
Food Manufacturing

## Project Objective
Build an end-to-end financial and cost intelligence platform that combines cost accounting, financial analysis, data engineering, business intelligence, and interactive decision support.

## Core Areas
- Cost Accounting
- Financial Analysis
- Financial Ratios
- Product Profitability
- Inventory Analysis
- Variance Analysis
- What-If Analysis
- Data Engineering
- Data Warehouse
- Business Intelligence
- Automation

## Technology Stack
- Python
- SQL Server
- Power BI
- DAX
- Power Query
- HTML
- CSS
- JavaScript
- APIs
- Web Scraping
- GitHub
- n8n

## Data Strategy
The project will use publicly available real-world datasets and sources. Any derived or synthetic assumptions will be explicitly documented.

## Project Approach
Raw Data → Data Collection → Data Quality → Transformation → Data Warehouse → Analysis → Power BI → Web Application → Automation → Decision Support
